# Vidyapaths — Website Project

## Project
Vidyapaths is a student-focused Career & Education Consultancy.

**Tagline:** Right Guidance. Brighter Future.

## Current Scope
This project is the ₹3,000 Basic Website / MVP.

The goal is to create a premium, modern, responsive public-facing website focused on:
1. Establishing Vidyapaths' online presence
2. Explaining its education/career services
3. Building trust
4. Generating student enquiries

## Included
- Home
- About
- Services
- Study Abroad
- Internships / Admissions
- Contact
- Lead/enquiry form
- WhatsApp CTA
- Responsive design
- Basic SEO
- Deployment

## Not Included in Current Scope
- Student login/signup
- Student dashboard
- Admin dashboard
- College/course database
- Online application tracking
- Internship portal
- Company accounts
- Document management
- Payment gateway
- OTP/SMS automation
- CRM integration
- AI features

These are Phase 2+ features.

## Brand
Primary: Deep Navy Blue (`#0B1F3A`)  
Secondary: Orange (`#F97316`)  
Background: White (`#FFFFFF`)

Visual direction:
- Premium
- Trustworthy
- Modern EdTech
- Student-focused
- Clean
- Minimal
- Mobile-first

Avoid a traditional/local consultancy appearance.
