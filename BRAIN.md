# VIDYAPATHS — PROJECT BRAIN

This file is the single source of truth for implementation.

## 1. Core Objective
Build a premium public-facing education consultancy website that converts visitors into student enquiries.

## 2. Audience
Primary:
- Students looking for college admission guidance
- Students looking for career guidance
- Students looking for internships
- Students interested in studying abroad

Secondary:
- Parents
- Graduates / career switchers

## 3. Brand Personality
Vidyapaths should communicate:
- Trust
- Guidance
- Growth
- Opportunity
- Confidence
- Professionalism
- Youthfulness

## 4. Visual Personality
Use:
- White/clean backgrounds
- Deep navy sections
- Orange accents
- Large confident headings
- Rounded modern cards
- Clean icons
- High-quality student imagery
- Generous whitespace
- Subtle motion

Avoid:
- Excessive gradients
- Excessive animations
- Clutter
- Too many colors
- Cheap-looking stock graphics
- Old-style consultancy layouts

## 5. Core Message
"Find the Right Path for Your Future."

Supporting idea:
Vidyapaths helps students make confident decisions about college, careers, internships and international education.

## 6. Primary Conversion
The main conversion is:
Visitor → Free Counselling Enquiry

Secondary conversions:
- WhatsApp
- Explore Colleges
- Study Abroad enquiry
- Internship enquiry

## 7. Main Services
1. College Admission & Guidance
2. Career Counselling
3. Internship Assistance
4. Study Abroad
5. Resume/Profile/Interview Support
6. Scholarship/Education Loan Guidance

## 10. Important Constraint
This is the ₹3,000 MVP.

Do not implement:
- Authentication
- Dashboards
- Databases
- Admin panel
- Application tracking
- Internship portal
- Payment
- CRM
- AI

## 11. Future Architecture
The UI leaves room for future:
- Student dashboard
- College database
- Internship system
- Counsellor dashboard
- Application tracking
- AI recommendations
- Scholarship finder
- College predictor

Do not prematurely build these systems.

## 12. Content Rule
Never invent:
- Testimonials
- Partner universities
- Student success statistics
- Accreditation
- Rankings
- Claims of guaranteed admission/jobs/visa

Use placeholders until the client provides verified information.

## 13. CTA Rule
Every major service section has a clear next action.

## 14. Responsive Rule
Mobile experience is not an afterthought. Design mobile and desktop together.

## 15. Change Control
Any feature outside README.md scope must be treated as a scope change.
