# Vidyapaths — Lead Form Specification

## Goal
Capture high-quality student enquiries without friction.

## Fields

### Required
- Full Name
- Mobile Number
- Email
- Current City
- Education / Qualification
- Service Required
- Interested Course
- Preferred Country
- Message / Query

### Optional
- WhatsApp Number
- Preferred College
- Preferred Intake / Admission Year

## Service Options
- College Admission
- Career Counselling
- Internship
- Study Abroad
- Scholarship
- Other

## User Flow
1. User opens enquiry form (via page or modal)
2. User fills details
3. Client-side validation (phone, email, required fields)
4. Submit
5. Show success message
6. Local lead storage + direct WhatsApp sync option

## Privacy Note
"By submitting this form, you agree to be contacted by Vidyapaths regarding your enquiry."
